# Microsoft 365 - Help Desk Administration & Troubleshooting

## Overview

This project simulates real-world help desk tasks and troubleshooting scenarios within a Microsoft 365 environment. Each scenario represents common issues handled by IT support professionals, including password resets, license management, Outlook access, Teams troubleshooting, and user administration.

The goal is to demonstrate the ability to troubleshoot, resolve, and document Microsoft 365-related issues using standard help desk workflows and Microsoft 365 administration tools.

## Objectives

- **Simulate real-world Microsoft 365 help desk tickets**
- **Troubleshoot common user access and sign-in issues**
- **Perform password resets and account administration**
- **Manage Microsoft 365 licenses and user settings**
- **Document troubleshooting steps and ticket resolutions clearly**

## Lab Environment

- **Platform:** Microsoft 365 Business Trial
- **Administration Portal:** Microsoft 365 Admin Center
- **Client OS:** Windows 11
- **Test Users:** Multiple simulated end users
